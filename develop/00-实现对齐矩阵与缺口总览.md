# 三项目实现与验收矩阵

基线为原工作树有效内容的隔离提交a211023。原运行目录没有修改；完整路径映射见[migration/source_inventory.json](../migration/source_inventory.json)。本表区分代码实现与外部验收，不以源码或单测存在代替柜台验收。

| 范围 | 维护项目 / 入口 | 验证边界 |
|---|---|---|
| 稳定实例、严格配置、迁移 | 本仓 src/core/config、quant_config_cli、strategy_state_migrate_cli | 配置及状态回归、参数重新物化比对 |
| 原子成交、策略经济账、账户实际账 | 本仓 trading_domain_store_client_adapter | 事务、双分配、去重、冻结和并发测试；目标数据库需独立迁移 |
| CTP、WAL、重连与退出 | 本仓 core/ctp、strategy_engine、pending_exit_store | SDK编译和离线事件回放；隔离SimNow仍需实际运行 |
| 策略、指标和纯规则 | quant_strategies 的固定静态包 | 自研指标、状态恢复、模拟时钟及包独立构建 |
| Tick、1m Bar、优化与EDB | quant_research | 固定快照回放；全市场覆盖需数据、日历和历史主力映射齐备 |
| P7与实盘 | 指定隔离账户；实盘另行切换 | 连续五个交易日、夜盘、断线与日切真实证据，尚未签收 |

构建及测试结果见[交付验证记录](../docs/results/three_project_split_validation.md)。回滚、运行身份和迁移约束见[操作说明](../docs/ops/three_project_migration.md)。
