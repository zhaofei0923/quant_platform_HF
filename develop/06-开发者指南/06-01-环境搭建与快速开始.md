# 独立构建

在WSL安装GCC11及以上、CMake3.20及以上、yaml-cpp、OpenSSL和GTest。先安装dependencies.lock.json指定且校验和一致的策略包。

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/installed/quant_strategies -DQUANT_HFT_BUILD_TESTS=ON
cmake --build build -j4
ctest --test-dir build --no-tests=error --output-on-failure
build/quant_config_cli validate configs/deploy/instances.example.yaml
```

示例部署路径需要指向实际安装包。真实CTP编译另给QUANT_HFT_ENABLE_CTP_REAL_API=ON和外部CTP_V6711_DIR；编译成功不表示账户已获准启动。运行入口与受限凭据要求见[部署说明](../../docs/ops/three_project_migration.md)。
