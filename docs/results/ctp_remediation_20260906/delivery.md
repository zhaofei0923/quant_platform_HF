## 使用与迁移

- 根目录 `.env` 已创建，账号、投资者编号及密码留空；文件受 Git 忽略。由用户本地
  填写，交易时段再测试。供应商 SDK 也位于忽略目录，未加入版本控制。
- `backtest_cli` 等 CLI 名称保留；默认 `behavior_profile=online_parity`、
  `parameter_profile=sim`，执行身份仍为 backtest。计算语义版本为 `3.0.0`。
  特殊连续价格、换月和旧研究协议须显式配置 research。
- 旧错误结果不作为兼容标准。多周期 Bar、预热、模拟成交先后顺序及风控修复可能
  改变研究结果；旧缓存无匹配身份时不命中。详见[研究语义及迁移](../../backtest_runtime_semantics.md)。
- 新版本使用稳定账户恢复目录。旧状态须复制核验，不直接接管身份、归属及成交
  覆盖边界不明的账户。详见[恢复和五日验收](../../ops/ctp_recovery_and_acceptance.md)。

## 验证范围和剩余事项

每阶段独立源码快照的构建与回归记录见[阶段 1](stage1_domain.md)、
[阶段 2](stage2_runtime.md)、[阶段 3](stage3_research.md)；最终集成结果以
[质量验证](quality_validation.md)为准。Arrow、真实 PostgreSQL、SDK
链接、ASan/UBSan 各有独立证据；关闭功能或缺少数据导致的跳过不计为通过。

最后仅执行一次 C++17 全量：944 项，922 通过、20 跳过、2 失败。两处分别为新会话
测试的代际预期和新增配置的文档索引遗漏；修正后只补验政策 20/20 及文档覆盖 1/1，
均通过，未重复全量。新增核算路径 ASan/UBSan 62/62 通过，官方 SDK 的主程序及
政策目标增量编译链接通过，真实 PostgreSQL 事务 6/6 通过。原始失败日志保留，
不能把定向复验描述成第二次全量通过。

仍需完成 SimNow 连续五个完整交易日（至少两个夜盘及一次交易日切换），验证真实
断线、重启、部分成交撤单、柜台核对和恢复耗时。WSL 的 TSan 在测试开始前遇到
宿主内存映射限制，尚无运行通过证据；远程 CI 未触发。

首版还有明确实现边界：WAL 校验快照上限 256 MiB、未完成多段连续恢复；非零
报撤单费及缺少历史核算证据的旧日未入账成交保持阻断；任意旧状态和已有持仓没有
自动接管转换器。Arrow 游标只约束读取批次，完整结果和轨迹仍需另计内存。
这些事项不能通过当前短样本或编排 smoke 宣称已完成。
