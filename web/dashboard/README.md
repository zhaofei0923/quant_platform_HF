# 个人量化交易看板

四个只读页面：账户总览、持仓价格与策略风控、订单与成交、策略与运行。
React / TypeScript / Vite / ECharts；服务器仅部署构建后的静态文件。

## 本地开发和验证

需要 Node.js 22.12 或更高版本。首次安装与构建：

```bash
cd web/dashboard
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:e2e
npm run dev
```

本地开发地址为 `http://127.0.0.1:5173`，开发服务仅监听回环。
默认没有账户数据，页面显示等待状态。开发服务不会读取交易运行目录、凭证或自动连接 CTP。
测试示例只放在 `tests/fixtures.ts`，由浏览器测试拦截请求注入，不进入生产构建。

浏览器测试覆盖电脑、390px 手机、过滤、空仓与未知状态、过期数据、登录跳转与退出、跨账户历史拒绝和坏数据恢复。
截图与测试临时文件在 `/tmp/quant-dashboard-browser-tests`，不放入发布包。
测试进程关闭继承的外发代理，确保本地请求不会被转发到外部代理。

## 数据与登录

应用每 2 秒串行读取 `/data/v1/current.json`，后台页面暂停刷新。
每个数据源独立判断时效，HTTP 请求成功不代表券商数据更新。
持仓页按“策略＋合约”显示最新价、生效止损和止盈价；多策略不合并，
未归属策略或与投机持仓不一致的数量明确标记。行情与风控行级时间超过
5 秒会显示过期，只有运行状态明确为休市时才显示“休市最后值”。
历史响应必须属于当前 `data_scope_id`；页面不存储账号密码、会话令牌或资金数据到本地存储。
使用官方登录门户 `/auth/`，退出跳转 `/auth/logout` 并立即清空页面数据。

权益历史按当前交易日筛选，横轴按真实采样点等距排列，压缩休市等无采样时段的空白。
超过 90 秒的采样间隔保留空值，并以短虚线连接前后真实点；虚线不代表中间存在权益采样，
也不将缺数原因认定为休市。悬停显示原始北京时间，间隔右端点同时显示前后时间。
图表不使用会丢弃空值的分桶采样；不计算未经出入金调整的投资收益率。
真实数据协议见 [接口说明](../../docs/ops/dashboard_data_contract.md)。
公网登录、域名、证书、安装和回滚见 [腾讯云部署说明](../../docs/ops/tencent_dashboard.md)。

发布目录为 `dist/`。通过仓库打包脚本与独立 C++ 发布器、认证服务组合发布。
不要将 Vite 开发服务开放公网，也不要将交易 runtime 直接作为网页目录。
